
## Getting started

```bash
$ npm install
```

Set up environment variables by renaming `.env.example` file to `.env` and modifying its values.

Set up database (requires docker)
```bash
docker-compose up -d database
```

Run the application

```bash
# development
$ npm run start

# watch mode
$ npm run start:dev
```
